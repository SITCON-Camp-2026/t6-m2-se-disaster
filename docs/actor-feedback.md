# 行動者（Actor）子代理回饋

這份文件整理了以「行動者」視角，對目前災害資訊整理工作台的回饋。內容以 persona 的固定格式呈現，重點放在「是否能安全採取下一步」而不是產品設計細節。

## 1. 我想完成的事

我想快速判斷這筆資訊現在是否適合讓我採取下一步行動，例如前往現場、聯絡人員、或停在原地再確認。

## 2. 我看不懂的地方

目前我不容易一眼看出：哪些資訊已確認、哪些只是候選、哪些還是需要人工確認。資訊看起來像是可執行，但其實仍然不夠安全。

## 3. 我最怕的錯誤

我最怕把未確認資訊當成已確認，然後到現場才發現任務已不存在、地點不對、或需求和實際情況不同。

## 4. 我不敢直接相信的資訊

我不敢直接相信來自社群貼文、口述回報、或沒有明確時間與查核者的資訊。這些資訊可能很有用，但不能直接當成可執行的行動依據。

## 5. 我希望系統提醒我的事

我希望畫面能清楚提醒我：

- 這筆資訊是否已被查核。
- 這筆資訊是否還有效。
- 這筆資訊是否有衝突或過期風險。
- 這筆資訊是否還不能直接變成任務。

## 6. 我想反問開發者的一個問題

如果一筆資訊還不夠完整，系統是否應該直接阻止我把它當成可執行任務，而不是只用普通的提示文字提醒我？
